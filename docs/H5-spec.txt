派对连续抓拍照片墙 H5 规格说明

一、项目目标

制作一个9:16竖屏移动端H5。

四张派对照片依次全屏出现，每张照片在相机闪光后定格，缩小并飞入页面的不同位置。四张照片最终形成不规则、轻微重叠的拍立得照片墙。

页面不添加标题、Logo、说明文字、按钮或进度条。

二、素材

assets/images/01_party.png
assets/images/02_party.png
assets/images/03_party.png
assets/images/04_party.png

不得修改、重命名或重新生成原始图片。

三、画面规格

1. 页面比例为9:16。
2. 使用100vw和100svh。
3. 适配iPhone、安卓手机和桌面浏览器。
4. 页面禁止滚动。
5. 禁止图片拖动、文字选择和双击缩放。
6. 背景为深灰黑色，带有细微胶片颗粒。
7. 所有核心动画必须在手机竖屏中完整可见。

四、照片样式

每张照片使用米白色拍立得边框：

上、左、右边框较窄；
底部边框略宽；
带真实柔和阴影；
轻微圆角；
照片本身保持原始9:16构图；
使用object-fit: cover；
不得拉伸变形。

五、动画流程

总时长约9秒。

0—0.5秒：
深灰黑色背景渐亮。
第一张照片准备进入。

0.5—1.7秒：
01_party.png全屏显示。
画面带有轻微手持晃动和1%至2%的缓慢推近。
约1.2秒时出现一次白色相机闪光。
闪光结束后照片定格，出现拍立得边框，并缩小飞入左上方。

照片1最终位置：
left: 5%;
top: 7%;
width: 49%;
rotate: -7deg;
z-index: 2;

1.7—3秒：
02_party.png从右侧快速进入并全屏显示。
保持轻微横向移动。
约2.5秒时出现相机闪光。
闪光后缩小飞入右上方，与照片1轻微重叠。

照片2最终位置：
left: 48%;
top: 18%;
width: 47%;
rotate: 6deg;
z-index: 3;

3—4.3秒：
03_party.png从下方略微放大进入。
约3.8秒时出现相机闪光。
闪光后缩小飞入左下方，并带有轻微弹性落下效果。

照片3最终位置：
left: 2%;
top: 49%;
width: 48%;
rotate: 4deg;
z-index: 4;

4.3—5.8秒：
04_party.png全屏出现。
画面带有轻微手持晃动。
约5.2秒时出现最明显的一次相机闪光。
闪光后缩小飞入右下方。
照片4比其他照片略大，并作为最上层主照片。

照片4最终位置：
left: 43%;
top: 55%;
width: 54%;
rotate: -5deg;
z-index: 6;

5.8—7秒：
四张照片完成照片墙组合。
照片产生一次轻微落桌动作：
向下移动约8px；
回弹约3px；
最后稳定。

照片阴影逐渐增强。

7—9秒：
完整照片墙稳定停留。
只保留非常轻微的整体呼吸缩放和1至2px视差。
最终稳定画面至少保持1.5秒。

六、相机闪光

每次照片定格前使用全屏白色闪光层。

闪光时长约200毫秒。

闪光节奏：
透明度0；
快速提升到0.9左右；
下降到0.3；
恢复到0。

闪光不能长时间遮住画面。
第四次闪光可以略强。

七、照片运动要求

1. 照片必须从全屏画面自然缩小到最终位置。
2. 不能直接硬切到照片墙。
3. 四张照片不能排成整齐网格。
4. 照片之间必须有轻微遮挡和不同旋转角度。
5. 缩放和位移动画应自然流畅。
6. 不允许照片突然跳位。
7. 不使用夸张的卡通弹跳。

八、交互

1. 页面加载后自动播放一次。
2. 点击或轻触任意位置后完整重播。
3. 快速连续点击不能叠加多套动画。
4. 重播前必须清除所有计时器和动画状态。
5. 重播时四张照片应全部返回初始隐藏状态。
6. 支持prefers-reduced-motion。
7. 减少动态模式下直接显示最终照片墙。

九、技术限制

1. 只使用原生HTML、CSS和JavaScript。
2. 不使用GSAP、React、Vue、jQuery或第三方框架。
3. 不使用CDN。
4. 不加载远程字体、图片、脚本或音频。
5. 所有素材使用本地相对路径。
6. 不创建重复的第二套页面。
7. 第一阶段先完成普通项目版，不生成Base64单文件。
8. 效果确认后，再单独打包standalone.html。

十、测试

完成后检查：

1. node --check js/main.js
2. git diff --check
3. python3 -m http.server 8765
4. index.html返回HTTP 200
5. 四张图片均返回HTTP 200
6. 页面控制台没有错误
7. 点击或轻触可以完整重播
8. 390×844画面完整
9. 1080×1920画面完整
10. 最终照片墙至少稳定停留1.5秒
